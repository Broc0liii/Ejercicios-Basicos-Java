# Ejercicios Básicos de Java - Programación Orientada a Objetos (POO)

Este repositorio contiene una colección de ejercicios prácticos desarrollados en Java para la materia de Programación Orientada a Objetos (POO) en la Universidad de Guanajuato.

## 📁 Contenido del Repositorio

- **`aprendiendoaimprimir/`**: Ejercicios introductorios sobre salida por consola e impresión de datos.
- **`clase10-09-2026/`**: Ejercicios desarrollados durante las sesiones de clase.
- **`CRUD_Extremo_Java_Miedo/`**: Ejercicios de gestión de datos mediante operaciones CRUD en Java.
- **`CRUD_POO/`**: Sistema completo CRUD aplicando principios de POO (clases `Alumno`, `GestorAlumnos` y `Main`).
- **`Declarar_Variables_Y_Concatenar/`**: Uso de variables, tipos de datos primitivos y concatenación de cadenas.
- **`Definir_Una_Clase/`**: Definición de clases, instanciación de objetos y prueba de métodos (`Persona`, `PruebaPersona`).
- **`ejerciciodeClase2/`**: Ejercicios prácticos con modelos de dominio (`BlockBuster`, `Producto`, `Juguete`, `Estado`).
- **`principal/`**: Proyectos base e introducción a clases en Java.
- **`SistemaUML/`**: Implementación de un sistema de biblioteca basado en diagramas UML (`Biblioteca`, `Libro`, `Material`, `Revista`).

## 🛠️ Requisitos
- **JDK 17** o superior.
- IDE recomendado: IntelliJ IDEA, Eclipse o VS Code.
